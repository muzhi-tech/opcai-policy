## 💡 什么是“一人公司” (OPC)？ 

在本仓库的语境下，**OPC (One-Person Company)** 泛指由单一个人出资、运营或控股的经济实体。在当前数字游民与 AI 赋能的时代，主要包括但不限于：
- **一人有限责任公司**（自然人独资）
- **个体工商户**
- **个人独资企业**
- 享受特定税收政策的**超级个体**与**自由职业者**

## 🤝 如何参与贡献 (How to Contribute)

一人公司的力量在于连接与开源。如果您发现了最新的政策文件、或者是某个园区的隐藏福利，欢迎提交更新，让更多超级个体受益！

1. **Fork** 本仓库。
2. 按照 `YYYY-MM-DD-发文机关-政策标题.md` 的命名规范，在对应目录添加 Markdown 文件。
3. 提交 **Pull Request (PR)**。
4. 如果您不熟悉 Git 操作，也欢迎直接提交 **[Issue](https://github.com/你的用户名/你的仓库名/issues)** 告诉我们政策线索！
